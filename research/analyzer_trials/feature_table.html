Which signals are worth chasing for the light show

Every piece of information we could put in the source of truth, ranked by one question: is it useful for a choreography and could the real-time analyzer on the Raspberry Pi realistically detect it later?

The two ratings are my judgement from how each signal is normally detected. None has been measured on the Pi. "Live" assumes one audio input, no lookahead, no instrument separation and no large models.

Priority

Show value × live confidence, from 1 to 25. A signal that would look great but cannot be detected live scores low, and so does one that is easy to detect but adds little.

Show value

  • carries the show on its own
  • clear improvement to a mode
  • hard to see a use

Live confidence

  • standard real-time signal processing
  • plausible, with visible mistakes
  • not realistic on the Pi
